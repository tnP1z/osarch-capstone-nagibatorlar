# Decision log

One entry per decision, newest at the bottom. Write it the same day the decision is made.
At the defence, any member may be asked about any decision — read this file before week 16.

Template:

```
## Decision N: <short title>
**Date:** dd.mm.2026
**Author:** <name>
**Considered:** option A, option B, option C
**Chose:** …
**Why:** …
**Cost:** what we give up by choosing this.
```

## Decision 1: one shared repository with fixed structure
**Date:** 24.11.2026
**Author:** Kadik
**Considered:** one repository per member; one shared repository
**Chose:** one shared public repository, structure from the brief (section 4.3)
**Why:** the brief requires it, and teamwork is graded on a single commit history.
**Cost:** all three of us work on the same branch history, so we must pull before pushing to avoid conflicts.
